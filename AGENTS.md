# Orient Tech Development Guidelines

## Project Overview
Orient Tech is a modern automotive storefront for tyres, wheels, vehicle care, and professional workshop fitment bookings.

## Tech Stack
- **Framework**: TanStack Start (React 19)
- **Styling**: Tailwind CSS v4
- **Routing**: TanStack Router (file-based routing under `src/routes/`)
- **Data & State**: TanStack Query
- **Build Tool**: Vite
- **Icons**: Lucide React
- **UI Components**: Radix UI primitives
